## Features
- Home, Puppies (breed and origin filters), puppy detail pages, Happy families, How it works, FAQ, Contact, Gone home
- Responsive layout with a mobile menu and WhatsApp enquiry buttons

## Tech stack
Next.js 14 (App Router), React 18, plain CSS, deployed on Vercel.

## Structure
- `app/` – pages and layout
- `components/` – Nav and Card
- `data/puppies.js` – all puppy data and content

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000
